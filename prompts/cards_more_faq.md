# FAQ 답 보강(cards_more.faqs) 작성 지시

작업 폴더: c:\side_Prj\shopa_prj. 받은 slug 마다 `content/cards/<slug>.json` 의 `faqs`(질문 q · 답 a 목록)를 읽고, 답마다 덧붙일 **한 문장**을 써서 `content/cards_more/<slug>.json` 에 `"faqs"` 키로 **추가**한다.
목적: 키워드 페이지의 FAQ 답이 한 개 60자 안팎으로 짧다. 답 뒤에 한 문장이 붙어 FAQ 4개 합이 약 250자 늘어난다(본문 1,800자 이상 목표).

형식: `"faqs": {"<카드 faqs 의 q 글자 그대로>": "덧붙임 한 문장", ...카드 faqs 전부}`
- 키는 카드 q 와 **한 글자도 다르지 않게**. 손으로 옮겨 적지 말고 파이썬으로 카드에서 q 목록을 읽어 키로 쓴다.
- 파일의 다른 키(criteria·methods·care·mistakes·checks·axes)는 **건드리지 않는다.** 파이썬으로 JSON 을 읽어 `"faqs"` 만 넣고 다시 쓴다(`json.dump(..., ensure_ascii=False, indent=1)`). 이미 `"faqs"` 가 있으면 그 slug 는 건너뛴다.
- 문장: 55~85자, "~요" 말투(~예요/~해요/~보세요). 답을 되풀이하지 말고 **다음 한 걸음**(어디서·어떻게 확인하나, 무엇과 견주나, 어떤 경우엔 다르게 하나)을 쓴다. 그 종류만의 낱말(부품·재질·쓰임)을 넣어 다른 종류에 옮기면 말이 안 되게. 카드 안의 다른 문장·다른 덧붙임과 같은 문장 금지.
- 금지: 아라비아 숫자, 물음표, 브랜드명, 지어낸 경험(써 보니·후기·만족), 과장(최고·완벽·무조건·보장), 효능 단정(치료·개선·면역·다이어트 효과), 판매처 이름, '공식·정품'. 금지어 목록 lint/forbidden.txt. 쿠팡 사이트 종류(용품)에는 '가전'이라는 낱말도 쓰지 않는다(카드 kind 가 data/coupang_kinds.json 에 있으면 쿠팡 종류).
- 식품·건강식품·화장품·유아용품·반려동물 먹거리·보호대류는 "제품 표기 확인"과 형태 차이만. 의학적인 대목은 "전문가(수의사)와 상의".

점검(통과할 때까지 고친다): `cd /c/side_Prj/shopa_prj && PYTHONIOENCODING=utf-8 .venv/Scripts/flask --app app jobs cards-load --check --only <slug>` — "보강 faqs 키가 카드 질문과 다름"이 나오면 키가 어긋난 것.
스스로 확인: faqs 키 집합 == 카드 q 집합, 문장 길이 55~85자, 숫자·물음표 없음, 다른 키가 그대로인지(작업 전후 비교).

스크래치 파일은 `scratchpad\<에이전트마다 다른 폴더 이름>\` 아래에만 둔다(다른 에이전트와 같은 폴더를 쓴다 — 남의 파일을 덮어쓰지 않는다).
다른 파일은 고치지 않는다. git·DB 적재(--check 없는 cards-load) 금지. 끝나면 slug 별 '통과/실패'만 한 줄씩 보고한다.

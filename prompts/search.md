# 검색 키워드 페이지 문장 작성 규칙 (content/search/<slug>.json)

입력: `content/search/_input/<slug>.json` — 실제 네이버 검색 키워드(월 검색수 순)마다 `kw`·`term`·`products`(그 말이 이름에 든 우리 상품).
출력: `content/search/<slug>.json` = `{"kind": "...", "items": [{"kw", "term", "monthly", "sents": [3문장]}]}` — 이미 있으면 items 뒤에 **덧붙이기만** 한다(기존 항목 수정·삭제 금지).

## 항목마다
1. `sents` 3문장. 이 종류에서 `term` 이 무슨 뜻인지 → 고를 때 무엇을 확인하면 되는지 → 어떤 사람·상황에 맞는지(또는 주의점).
   - 브랜드면: `products` 상품명에 보이는 라인·형태·구성(예: "탄소 매트와 전기요 두 가지가 보여요")만 근거로 쓴다. 회사 연혁·점유율·품질 평가 금지.
   - 특징·형태·크기·대상이면: 그 말이 뜻하는 구조와 확인 방법(상세 표기에서 무엇을 볼지).
2. 말투: 블로그 말투(~예요/~해요/~하세요). 반말·이모지·감탄 금지. 문장마다 35~90자.
3. 금지: 숫자 성능(전력 몇 W, 몇 평 등은 "상세 표기 확인"으로), 가격·할인·평점·순위, 최상급(최고·1위·최저가·가성비갑·끝판왕·역대급·꿀템 — lint/forbidden.txt), 효능·건강 효과 단정, 써 본 척(직접 써 보니 등), 다른 브랜드 깎아내리기.
4. 같은 문장·같은 틀을 항목끼리 돌려 쓰지 않는다. 카드(content/cards/<slug>.json) 문장을 그대로 베끼지 않는다.
5. `kw` 는 자연스러운 띄어쓰기로 다듬어도 된다(예: "1인용 전기매트"). `term` 은 바꾸지 않는다.
6. **같은 뜻은 하나만**: 1인용·1인·싱글, 침대·침대용, 워셔블·세탁가능·빨아쓰는, 보이러·보이로(표기 차이)처럼 뜻이 같으면 검색수 많은 하나만 쓰고 나머지는 뺀다 — 거의 같은 페이지가 여러 쪽 생기면 안 된다.
7. **뺄 항목**: 상품 속성이 아닌 말(요리 재료 "고구마", 지명, 쇼핑몰 이름, 모델 번호만 있는 것, 뜻이 불분명한 것)이나 `products` 가 그 말과 실제로 안 맞으면 쓰지 말고 빼라. 억지로 채우지 않는다.

## 점검
`PYTHONIOENCODING=utf-8 .venv/Scripts/flask --app app jobs cards-load --check --only <slug>` 통과까지 고친다(형식·중복·린트).
